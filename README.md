# Pharmacy Management System in C#

## Project Overview
This repository contains a **Pharmacy Management System** developed in **C#** for Windows desktop environments. The application simulates core pharmacy operations including selling medicines, managing stock, handling orders, and providing separate dashboards for pharmacists and sellers.

## Features
- User sign‑in and authentication
- Seller and pharmacist dashboards
- Add, update, and remove medicine records
- Process medicine sales and transactions
- Track inventory and medicine validity
- View all orders and customer details
- Simple Windows desktop interface

## Technology Stack
- **C#** – Core language for application logic
- **.NET (Windows Forms)** – Desktop UI framework
- **Data Files / Local Storage** – Stores application data
- **Visual Studio** – Recommended IDE for development
